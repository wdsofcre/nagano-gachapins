長野版 ガチャピンズラリー管理アプリ v4

【主な修正】
・長野県SVGの県域部分に合わせて緯度経度の投影範囲を補正
・ピンを押したときの駅名表示を、地図上の吹き出しから地図下の詳細カードへ変更
・画面端のピンでも駅名や操作ボタンが切れないように修正
・古いキャッシュを消すためService Workerのキャッシュ名を更新

【起動】
index.htmlをブラウザで開いてください。
PWAとして使う場合は、HTTPSで公開してiPhoneのSafariから「ホーム画面に追加」します。

【以前の版を使っていた場合】
古い表示が残る場合は、ホーム画面から旧アプリを削除し、Safariのサイトデータを削除してから再登録してください。


v6変更点：地図上の駅名ポップアップを復活。北側の駅はピンの下、南側の駅はピンの上に表示し、左右端では枠が地図内に収まるよう自動補正します。


v7: ピンの実際の表示枠を基準に、上下の吹き出し間隔を14pxで統一。
